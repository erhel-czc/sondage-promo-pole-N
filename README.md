# Pole N Survey Analysis

Brief analysis of a student survey about expectations for company-related events (domains, forums, motivations, preferred job functions, and information needs).

For full methodology and interpretation, see `rapport.pdf` (or `rapport.lyx`).

## Structure
- `analysis.ipynb`: main analysis notebook
- `data/poll.csv`: raw survey data
- `requirements.txt`: Python dependencies
- `plots/`: exported figures (`.pdf`, `.svg`, `.eps`)
- `img/`: additional images

## Run
1. Open `analysis.ipynb`.
2. Install dependencies: `pip install -r requirements.txt`.
3. Run all cells.
